Reports case <-time.After(...) inside a Go select block, in a module that targets Go before 1.23.

Until Go 1.23, the timer created by time.After is not released until it fires, so a select inside a loop keeps a new timer alive on every iteration. A time.NewTimer(...) stopped explicitly works in every version.

When the nearest go.mod declares go 1.23 or later, the garbage collector recovers unstopped timers and nothing is reported. A module without a go line keeps the warning.
